# constants/

Reserved for shared, cross-cutting constants (route paths, shared config
values, enum-like literals used in more than one place). Domain enums
(`Role`, `Persona`, `CourseLevel`, etc.) already live in `prisma/schema.prisma`
and are generated by Prisma — don't redeclare them here, import from
`@prisma/client` instead.

Values like `MAX_FILE_SIZE` in `app/api/materials/upload/route.ts` and
`app/api/settings/avatar/route.ts` look similar but are intentionally
different (50MB for course materials vs. 2MB for avatars, with different
MIME/signature allowlists) — they were left as-is rather than force-merged
into a shared constant.
